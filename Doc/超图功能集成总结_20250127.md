## 主要修改文件

### 1. `model/SMGCN.py`

#### 问题修复
- **属性名不一致**: 修复了`emb_size`与`emb_dim`属性名不一致的问题
- **缺失data_path属性**: 在初始化中添加了`self.data_path = args.data_path + args.dataset`
- **MLP层维度不匹配**: 修正了MLP预测层的输入输出维度配置

#### 具体修改
```python
# 添加data_path属性
self.data_path = args.data_path + args.dataset

# 修正MLP层维度配置
self.mlp_predict_weight_size_list = [self.emb_dim] + self.mlp_predict_weight_size + [self.emb_dim]
self.mlp_predict_n_layers = len(self.mlp_predict_weight_size) + 1
```

### 2. `smgcn_main.py`

#### 超图功能集成
- **启用超图功能**: 设置`args.use_hypergraph = True`
- **自动数据加载**: 在模型初始化后自动加载草药训练数据
- **超图构建**: 自动构建超图邻接矩阵
- **对比学习集成**: 将超图对比学习损失融入训练循环
- **损失打印更新**: 在训练日志中添加超图对比学习损失信息

#### 关键代码片段
```python
# 启用超图功能并加载数据
args.use_hypergraph = True
model.load_herb_train_data()
model.build_hypergraph()

# 训练循环中的损失计算
user_embeddings, all_user_embeddings, i_g_embeddings, cl_loss_user, cl_loss_item, cl_loss_hypergraph = model(users, pos_items, neg_items)
batch_loss = mf_loss + emb_loss + model.contrastive_weight * cl_loss_user + model.contrastive_weight * cl_loss_item + cl_loss_hypergraph
```

## 解决的关键问题

### 1. 维度匹配问题
- **问题**: `RuntimeError: mat1 and mat2 shapes cannot be multiplied`
- **原因**: MLP层输入输出维度不匹配
- **解决**: 重新配置`mlp_predict_weight_size_list`，确保输入输出维度与嵌入维度一致

### 2. 返回值数量不匹配
- **问题**: `ValueError: too many values to unpack (expected 5)`
- **原因**: `forward`方法返回6个值，但主程序只接收5个
- **解决**: 更新主程序中的变量解包，接收`cl_loss_hypergraph`

### 3. 属性缺失问题
- **问题**: `AttributeError: 'SMGCN' object has no attribute 'data_path'`
- **原因**: 模型初始化时未设置`data_path`属性
- **解决**: 在`__init__`方法中添加`self.data_path`属性
